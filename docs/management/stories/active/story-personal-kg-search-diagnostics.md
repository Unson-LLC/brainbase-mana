# 個人KG検索の実行結果を本文を保存せず確認する

## 利用者の目的

運用担当者として、Slackの個人KG検索依頼で実際に検索が成功したかを確認したい。返信が正しいことと検索ツールが実行されたことを分け、個人の本文を運用ログへ追加せず検証する。

## 受け入れ基準

- Claudeの各実行が返すstreamから、完全名が一致する検索tool_useと対応するtool_resultだけを確認する。
- Slack event IDに紐づく記録に、成功・失敗・不明、queryハッシュ、検索結果のevent_idと本文ハッシュ、件数を残す。
- 欠落、壊れた入力、対応関係の衝突、上限超過を成功や検索0件にしない。
- parse前にサイズを制限し、生本文・認証値・任意のエラー文字列を出力しない。
- 診断の失敗は返信処理と既存の最終監査判定を変更しない。
- 本番DMを連続2回送信し、各検索の直接証跡、既知記録との一致、同一スレッドの返信1件、Host最終監査を確認する。本番未検証を完了扱いしない。

## 範囲

検索の観測のみ。受付リアクションとスレッド状態更新で観測されたslack_api_unavailableは別件として原因と修正を追う。
